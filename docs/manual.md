# FreightFlow 操作手册

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 商业咨询微信 zhuatech / zhuatech2。

## 建立可执行的运输档案

1. 管理员登录，在账号管理创建调度、财务、司机和客户账号，选对应初始化角色与运营部门。密码至少12位，含大小写字母及数字。
2. 创建承运商。创建车辆并填写载重kg、容积m³、最大件数，关联承运商与部门。
3. 创建司机，绑定对应司机登录账号、承运商和部门，录入证件截止日期。客户档案可绑定对应客户门户账号，也可由内部代录且不开放门户。
4. 客户/司机关联账号必须采用ASSIGNED范围；客户只允许客户权限，司机只允许司机权限。关联身份有历史业务后不可换人，未完成车次关联账号不可停用。
5. 报销必须由另一名有财务权限的账号审核。管理员可创建更多财务账号，但不能审核自己填报的费用。需重新登录不同账号执行独立审核。

## 托运、报价、派车

客户录入装卸地址、收货人、货物、件数、重量和体积；客户身份由登录账号确定，不能代其他客户录入。调度查看草稿，确认客户运价后进入待配载。

新建车次，选择同部门同承运商的司机与车辆、计划起止时间和约定承运费。录入时间采用系统时区；计划最长30天，开始不能超过未来90天，结束不能早于当前时间。车次草稿立即预留资源，避免多人重复安排。

在车次详情添加待配载运单；三个容量同时校验。可在草稿中说明原因移出运单。派车后由真实司机接单，不允许调度或管理员冒充；司机接单后，在计划开始前12小时以内可确认发车。

## 回单与异常

司机在手机或电脑登录，查看本人车次和运单，上传原始PNG/JPEG签收照片（每张≤2MiB、每运单≤5张、≤2000万像素），重复相同图片不会重复登记。提交实际签收人和全量实收件数；不支持将少量签收误记为全量签收。

遇到延迟、破损等情况登记异常及说明。调度填写处理结果解决异常。提交回单后，调度查看照片与记录，复核通过才算已签收；照片不清楚可说明原因退回，司机重新补图、重新提交。原照片与历史记录保留。

## 费用与结算

司机/内部岗位在运输中填报燃油、通行费、停车或其他费用，附实际金额、凭证号和说明。财务由不同账号核准或退回；退回记录保留，需重新填报时创建新的费用记录。核准费用全部视为需向承运商报销的费用，本版不区分自付费用、税或加价。

所有运单签收、异常解决、费用审核后，调度结束运输关单并释放资源。

财务客户应收可按同一客户选择多个已签收运单；承运应付按已关单车次建立，包含约定承运费和核准报销。对账单可记录多次真实收付款，必须选择有效字典方式及凭证号，不支持超付或分以下金额。

录错金额时选原PAYMENT流水冲正，填金额、冲正凭证及原因；原流水不删，冲正金额不能超过该流水剩余可冲正金额。完全未产生任何收付款流水的对账单可说明原因作废，并释放原单据重新对账；已经产生流水的账单（包括全冲正）不支持作废。

打印运单/配载清单/对账单，输出不包含广告。报表CSV分别统计期间关单收入成本利润、期间净现金、全部时点未收未付余额；冲正在发生日扣减现金，不追溯改写原付款日期。

## 导入、筛选和权限管理

运单列表可按搜索、状态筛选、排序、分页查看。JSON导入必须是1–200个运单对象数组，任一行校验失败整批回滚；导入格式见接口文档。客户导入仍只能创建本人草稿。

系统管理允许编辑角色权限和数据范围，权限目录仅修改说明，菜单决定可见入口但不能绕过接口权限。部门不等于独立租户，系统参数全企业共享；ASSIGNED范围要求真实业务关联。币种和时区应在首次创建业务数据前设定，之后不可改变。
