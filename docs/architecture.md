# 架构与一致性

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2。

浏览器 → 同源Nginx → Spring Boot服务 → MySQL。前端仅控制表单与展示；服务端认证、功能权限、部门/本人对象范围与状态检查共同决定写入。

TransitService处理运输，ProofService校验与存储照片，FinanceService处理费用和冻结账单，ViewService裁剪字段及统计，MasterService与AdminService处理基础档案/账号设置。CommandService对账号、动作、请求键与规范化内容摘要进行幂等校验。每次写入在事务开始先锁默认部门配置记录，再读取业务状态；配合READ_COMMITTED，防止多个会话同时占用资源、重复开票或超额收付。事务统一回滚，业务revision拒绝旧页面写入。

当前实现以单企业中小规模使用为边界，全部业务写入共用事务锁。它优先保障一致性，不能宣称支持高吞吐分布式调度。列表每页最多100条，每类最多加载10000条，达到上限明确报错；大数据量场景需要数据库分页、分片锁与进一步容量测试。

客户只读取本人的运单、回单及应收账单；司机只读取实际关联车次货物，响应删除客户运价、承运费用和账单字段。账号/角色/密码变动即时复核；旧密码对应会话不再有效。菜单隐藏不是安全边界。

时间戳与数据库会话UTC；计划输入按企业时区换算，夏令时歧义/缺失分钟拒绝。统计按当前配置业务日切，且存在业务后锁定时区与币种。金额使用BigDecimal与DECIMAL，拒绝默默舍入。

回单存储原始二进制、SHA-256、大小、类型、关联运单与上传人；下载经对象权限复核，无本地路径或外部存储凭证。照片随数据库备份恢复。客户运价与车次承运费在业务记录中存储，账单生成时冻结独立明细，后续不能覆盖财务流水。
