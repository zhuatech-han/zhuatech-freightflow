# 安全与配置边界

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2。

账号无公开注册；BCrypt成本12，12–72位密码包含大小写字母及数字。会话Cookie HttpOnly、SameSite=Strict、默认30分钟。登录时旋转会话；写接口校验CSRF，密码变更/停用/权限调整实时校验。登录错误短期限流为进程内保护，不能代替网关限流。

初始化脚本仅写入0600私有.env，拒绝覆盖。数据库没有主机端口，前端默认127.0.0.1。HTTPS运营请配置域名证书、可信反向代理，并设置COOKIE_SECURE=true。外部数据库连接须验证TLS证书；默认Compose内网连接只用于隔离网络。不要将容器内部端口或管理员接口直接暴露公网。

每个接口校验权限，按ALL/DEPARTMENT/ASSIGNED范围复核对象，不接受任意实体名或排序SQL。客户不能设置他人身份，司机响应不返回财务字段。账户绑定档案后不能提升至不适用的角色。功能菜单与数据范围应由管理员检查，权限不是仅靠前端隐藏。

上传PNG/JPEG进行真实解码、像素与大小限制，≤2MiB/张，最多5张/运单。图片内容存入数据库，下载按运单范围并返回nosniff、no-store、sandbox等头。文件名不作为存储路径；不支持SVG、HTML或任意附件。网关限制3MiB请求。大文件可能由网关直接拒绝，客户端应检查图片后重试。

不记录密码、凭证、Cookie、回单内容或整份业务请求。审计记录操作人/时间/动作/对象及部门；业务事件保留状态与必要原因。备份包含业务与照片，必须加密存储、限制访问、规定保留期限并实际演练恢复。

发现安全问题请通过官方微信 zhuatech / zhuatech2 私下反馈，不在公开Issue附细节或真实数据。公开发布检查扫描已知密钥格式并检查示例密码为空；扫描不等于没有全部安全风险，企业上线需审查实际配置与业务范围。
